# LB Ofertas — Landing Page

Landing page responsiva para o grupo do WhatsApp LB Ofertas Exclusivas.

## Arquivos
- `index.html` — página
- `style.css` — estilos
- `script.js` — interações
- `assets/lb-ofertas.jpg` — imagem da marca enviada

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie estes arquivos mantendo a pasta `assets`.
3. Vá em **Settings → Pages**.
4. Em "Build and deployment", escolha **Deploy from a branch**.
5. Selecione a branch principal e a pasta `/ (root)`.
6. Salve e aguarde o GitHub gerar o endereço `github.io`.

O botão do WhatsApp já está configurado com o link do grupo fornecido.
